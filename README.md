# TP-S1-Travaux Pratiques (TP)

Ce dépôt contient l'ensemble des travaux pratiques (TP) et des exercices de programmation réalisés dans le cadre du module **TP-S1**.

## 📁 Structure du Projet

Le projet est organisé en plusieurs dossiers correspondant aux différentes séances de travaux pratiques :

* **`TP1/`** : Exercices d'initiation et premiers scripts en Python.
  * `exercice1.py` à `exercice12.py` : Scripts de base et algorithmes fondateurs.
  * `nn.py` : Script additionnel.
* **`TP2/`** : Approfondissement et structures de contrôle.
  * `ex1.py` à `ex8.py` : Exercices pratiques axés sur les boucles, les conditions et les fonctions.
* **`TP3/`** : Projets et exercices avancés.
  * `ex1.py` à `ex9.py` (incluant des variantes comme `ex6,2.py`) : Résolution de problèmes algorithmiques plus complexes.

## 🛠️ Technologies Utilisées
* **Langage** : Python 3.x
* **Environnement** : VS Code / Windows
* **Version Control** : Git & GitHub
